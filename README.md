# Parking System Project

This project is part of the **DIO Fullstack Bootcamp** and demonstrates basic **C# console application development**.

## Description

The application simulates a **simple parking management system** where users can:

- Register vehicles
- Remove vehicles and calculate parking fees
- List all currently parked vehicles

It focuses on **object-oriented programming concepts**, including classes, methods, lists, and basic user input/output in C#.

## How to Use

1. Run the program.
2. Enter the initial parking price and price per hour.
3. Use the menu to:
   - Add vehicles
   - Remove vehicles
   - List parked vehicles
   - Exit the program

## Technologies Used

- C#
- .NET
